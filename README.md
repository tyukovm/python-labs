**Описание лабораторной работы**

Цель работы: сбор информации о системе с помощью встроенных модулей в Python и сохранение результата в файл JSON.

Использованные модули:
1. **platform** - получение информации об ОС, ее версии и архитектуре процессора.
2. **os** - работа с операционной системой.
3. **sys** - доступ к параметрам интерпретатора Python.
4. **getpass** - получение имени текущего пользователя системы.
5. **json** - запись данных в формат JSON.

Что реализовано:
Скрипт собирает базовую информацию о системе, на которой он запущен, формирует из нее словарь и сохраняет результат в файл os_report.json в удобном для прочтения виде.

Использованные функции:
- platform.system() - возвращает название ОС (переменная os_name создана, чтобы вместо технического имени Darwin вывести macOS).
- platform.release() - возвращает версию релиза.
- platform.version() - возвращает подробную версию сборки ОС.
- platform.machine() - возвращает архитектуру процессора.
- platform.processor() - возвращает название/тип процессора.
- os.cpu_count() - возвращает количество логических ядер CPU.
- platform.python_version() - возвращает установленную версию Python.
- sys.executable - возвращает путь к используемому интерпретатору Python.
- platform.node() - возвращает сетевое имя компьютера.
- getpass.getuser() - возвращает имя текущего пользователя ОС.

json.dump(report, f, indent=4) - запись собранных данных в файл в формате JSON с отступом 4 пробела для лучшей читаемости.
